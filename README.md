# 🍴 Omnifood

A modern and responsive food delivery website built using **HTML5 and CSS3**.  
The project focuses on creating a clean, professional landing page for a healthy meal delivery service.

## 🌐 Project Overview

Omnifood is a food service platform that provides healthy and personalized meals to customers.

This project was created to practice:

- HTML5 structure
- CSS3 styling
- Responsive web design
- Flexbox and Grid
- Navigation menus
- Hero sections
- Website layouts
- Google Fonts
- Images and background images

## ✨ Features

- Responsive navigation bar
- Hero section with background image
- Call-to-action buttons
- Features section
- Meal/food showcase
- Responsive image grid
- Customer-focused sections
- Modern typography
- Responsive layout for different screen sizes
- Clean and simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Media Queries
